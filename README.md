## 🛠️ Technology Stack

- **HTML** - Semantic structure with multi-page navigation
- **CSS** - Styling for layout, colors, typography, and responsive design

## 🎯 Project Purpose

This project was developed as a hands-on exercise to:
- Practice fundamental HTML and CSS concepts
- Learn multi-page website structure and navigation
- Implement styling and layout techniques
- Create visually appealing web pages
- Understand CSS styling for better user experience

## 🚀 Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Navigate through different pages using the navigation menu

## ✨ Features

- Multi-page navigation system
- CSS-styled layout and typography
- Visually appealing color scheme and spacing
